Estructura del Proyecto

El proyecto está organizado de la siguiente manera:

    /services/
    Contiene la lógica para las peticiones HTTP hacia el backend utilizando fetch.

    /routes/
    Incluye las rutas principales y protegidas de la aplicación.

    /pages/
    Contiene los componentes principales de las páginas visuales.

    /layouts/
    Contiene componentes reutilizables como el Navbar, Footer, y otros elementos compartidos.

    /contexts/
    Define la lógica para manejar rutas protegidas y acceso a las mismas mediante Context API.

    /components/
    Componentes reutilizables que manejan la interacción entre el cliente y la UI.

    /assets/
    Almacena los recursos de diseño como imágenes, iconos, y estilos.
